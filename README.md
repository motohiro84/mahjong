# 牌しるべ

初心者向けのリーチ麻雀・手牌確認アプリです。手牌を入力すると、シャンテン数、有効牌、狙える役、成立役、翻・符・点数と支払い方を確認できます。

「どんな役を作れるのか分からない」「ロンとツモで誰から何点もらうのか分からない」という段階でも、対局中に素早く確認できることを目標にしています。

## 主な機能

- 13枚・14枚の状態に応じて切り替わる高速な牌入力
- 赤5、ドラ表示牌、場風・自風の入力
- ポン、チー、明槓、暗槓、加槓
- チー候補と赤5を、必要な場合だけ選択
- 喰い替え防止、リーチ状態、捨て牌、フリテンの端末内記録
- シャンテン数と有効牌
- ロン可能・ツモ可能・役なしの確認
- 狙い目の役と構成例
- 成立役、翻、符、点数、支払い者の表示
- 全役一覧、基本ルール、用語集
- 1手戻す、リセット
- ブラウザを閉じても入力を保持する端末内保存
- ホーム画面追加とオフライン起動に対応するPWA

## 技術構成

- Next.js 16（App Router）
- React 19
- TypeScript
- CSS（外部UIライブラリなし）
- LocalStorage（手牌・設定の保存）
- Service Worker / Web App Manifest（PWA）

麻雀の計算処理はUIから分離しています。

```text
app/                  ページ、メタデータ、PWA Manifest
components/           React UI、状態管理、牌の表示
lib/shanten.ts        シャンテン数・有効牌
lib/scoring.ts        役判定・符・点数・支払い
lib/yaku-guide.ts     狙い目判定
lib/analysis.ts       打牌・副露・リーチ・フリテン
lib/reference-data.ts 全役・ルール・用語集
public/sw.js          オフラインキャッシュ
tests/                主要な回帰テスト
```

## ローカル起動

Node.js 20.9以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。


## Vercelへデプロイ

1. このディレクトリをGitHubなどのGitリポジトリへ登録します。
2. Vercelで「Add New Project」からリポジトリを選びます。
3. Framework Presetが `Next.js` になっていることを確認します。
4. Build Command、Output Directory、環境変数は変更せずにデプロイします。

サーバーやデータベースは使用していないため、追加の環境変数はありません。

## PWA・オフライン利用

Vercelへデプロイ後、対応ブラウザの「ホーム画面に追加」からアプリとして追加できます。一度オンラインで開くと、表示に必要なファイルがキャッシュされ、圏外でも主要ページと麻雀計算を利用できます。

- 手牌と設定は端末内に保存されます。
- 別の端末や別のブラウザとは同期されません。
- アプリ更新は、次にオンラインで開いたときに取得されます。
- 開発環境ではService Workerを登録しません。PWA確認は本番ビルドまたはVercel上で行ってください。

## 採用ルール

日本で一般的な4人打ちリーチ麻雀を基準にしています。

- 喰いタンあり
- 赤ドラあり
- 数え役満あり
- 役牌の白・發・中は、刻子または槓子で1翻
- ドラだけでは和了不可

次の項目は現在、自動計算の対象外です。

- 一発
- 海底摸月・河底撈魚
- 嶺上開花・槍槓
- ダブル立直
- 天和・地和
- 本場・供託
- 切り上げ満貫
- ダブル役満

卓ごとに採用ルールが異なる場合があるため、実戦では卓のルールを優先してください。

## テストしている重要ケース

- 副露を含む一気通貫が、成立役と狙い目の両方に表示される
- 役牌の白で和了できる
- 一気通貫の完成前がテンパイとして案内される

「牌しるべ」は、初心者が手牌から役と次の一手を見つけるための「道しるべ」という意味で付けています。
