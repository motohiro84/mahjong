# 麻雀手牌確認アプリ

リーチ麻雀を覚え始めた人が、対局中に手牌・有効牌・役・点数を素早く確認するためのスマートフォン向けWebアプリです。

手牌は画面上部に固定され、選択中の分析内容だけがスクロールします。入力内容は端末内に保存されるため、ブラウザを閉じても続きから確認できます。

## できること

- 13枚の配牌、ツモ牌、打牌、赤五の入力
- ポン、チー、明槓、暗槓、加槓と喰い替え制限
- 場風・自風、表ドラ表示牌の設定
- シャンテン数、有効牌の種類数と残り枚数の表示
- 他家の捨て牌を「場の牌」として登録し、有効牌の残り枚数へ反映
- 自分の捨て牌によるフリテン判定
- ロン・ツモ・リーチと、役なし状態の確認
- 狙える役、成立役、待ち方、翻・符・点数、支払い方法の表示
- リーチ和了時の裏ドラ表示牌入力
- 表ドラ・裏ドラ・赤ドラの個別集計
- 一発・ダブル立直・嶺上開花・天和・地和の操作順による初期判定
- 海底・河底・槍槓など、和了時の状況役の指定
- 本場・供託、切り上げ満貫、ダブル役満を含む点数計算
- 34種の牌画像を使った、スマートフォンでも判別しやすい牌表示
- 全役一覧、基本ルール、用語集
- 1手戻す、リセット、端末内への自動保存
- ホーム画面への追加とオフライン起動に対応するPWA

## 基本的な使い方

1. 手牌タブで13枚を入力します。
2. 必要に応じてヘッダーから場風・自風と表ドラ表示牌を設定します。
3. ツモ牌を入力すると、捨て牌候補や和了可否を確認できます。
4. 他家の見えている捨て牌は「場の牌」タブから登録します。
5. 「有効牌」「狙い目」「成立役」を切り替えて確認します。

リーチ和了後は、成立役タブ上部の「裏ドラ 0/N」から裏ドラ表示牌を入力できます。裏ドラはリーチ時のみ計算され、入力できる枚数は表ドラ表示牌の枚数までです。

成立役タブの「和了時の状況」では、一発、海底・河底、嶺上開花・槍槓、ダブル立直、天和・地和を確認・変更できます。本場・供託の本数と、切り上げ満貫・ダブル役満の採用有無も同じ場所で設定します。

### ヘッダーの枚数表示

- `構成`：シャンテン計算上の枚数。槓子は3枚相当として数えます。
- `実牌`：画面上にある物理的な牌の枚数。カン1回につき構成より1枚多くなります。
- 360px以下の画面では、`牌 14/15`のように「構成／実牌」をまとめて表示します。

## 採用ルールと計算範囲

日本で一般的な4人打ちリーチ麻雀を基準にしています。

- 喰いタンあり
- 赤ドラあり
- 数え役満あり
- 役牌の白・發・中は刻子または槓子で1翻
- ドラだけでは和了不可
- 裏ドラはリーチ和了時に入力した表示牌から計算
- 本場はロン時に1本300点、ツモ時に各自100点を加算
- 供託は1本1,000点を和了者の受取合計へ加算
- 切り上げ満貫とダブル役満は初期状態では不採用。成立役タブで変更可能

### 状況役の判定

- 一発：リーチ宣言時に自動選択し、次の自分の打牌で解除します。他家の鳴きは記録していないため、鳴きが入った場合は成立役タブで外します。
- ダブル立直：副露せず、自分の最初の打牌でリーチした場合に自動選択します。
- 嶺上開花：明槓・暗槓・加槓後の嶺上牌入力時に自動選択し、打牌すると解除します。
- 天和・地和：副露・自分の打牌がない最初の和了形で、親なら天和、子なら地和を自動選択します。他家の鳴きが入っていた場合は外します。
- 海底摸月・河底撈魚・槍槓：山や他家の加槓を追跡していないため、成立役タブで指定します。
- 海底と嶺上、河底と槍槓は同時に選択できません。

ダブル役満を採用すると、四暗刻単騎、国士無双十三面待ち、純正九蓮宝燈、大四喜を2倍役満として計算します。別々の役満が複合した場合の役満加算は、設定にかかわらず行います。

卓ごとに採用ルールが異なるため、実戦では卓のルールを優先してください。

## 「場の牌」の扱い

「場の牌」は、他家の長考中などに見えている捨て牌を登録し、有効牌の残り枚数を確認するための機能です。

- 誰が捨てたかは区別しません。
- 自分の捨て牌は打牌時に自動記録されます。
- 他家の捨て牌は有効牌枚数には反映されますが、自分のフリテン判定には使用しません。
- ロン・ポン・チーなどの操作とは連動しません。

## 技術構成

- Next.js 16（App Router）
- React 19
- TypeScript
- CSS（外部UIライブラリなし）
- LocalStorage（手牌・設定の保存）
- Service Worker / Web App Manifest（PWA）

麻雀の計算処理はUIから分離しています。

```text
app/                  ページ、スタイル、メタデータ、PWA Manifest
components/           React UI、状態管理、牌コンポーネント
lib/shanten.ts        シャンテン数・有効牌
lib/scoring.ts        役判定・ドラ・符・点数・支払い
lib/yaku-guide.ts     狙い目判定
lib/analysis.ts       打牌・副露・リーチ・フリテン
public/tiles/generated/ 34種の牌画像（各180×240pxの透過PNG）
lib/reference-data.ts 全役・ルール・用語集
public/sw.js          オフラインキャッシュ
tests/                主要な回帰テスト
```

## ローカル起動

Node.js 20.9以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

```bash
npm run build
```

## PWA・オフライン利用

本番環境を一度オンラインで開くと、表示に必要なファイルがキャッシュされ、圏外でも主要ページと麻雀計算を利用できます。

- 手牌と設定は端末内に保存されます。
- 別の端末やブラウザとは同期されません。
- 更新は次にオンラインで開いたときに取得されます。
- 開発環境ではService Workerを登録しません。

## Vercelへのデプロイ

GitHubなどへ登録したリポジトリをVercelから選択し、Framework Presetを`Next.js`のままデプロイします。サーバーやデータベースを使用しないため、追加の環境変数はありません。

## 回帰テストで確認している内容

- 副露を含む一気通貫と三色同順
- 役牌の成立
- テンパイ時の案内
- 赤五でロンした場合の赤ドラ
- 暗槓取り消し時の枚数保護
- ツモのみ可能な役なしテンパイ
- 加槓を含む両面待ちの符・点数
- 裏ドラがリーチ時だけ加算されること
- 他家の捨て牌が有効牌を減らし、フリテンにはしないこと
- 一発・ダブル立直・天和・地和の操作順による初期選択
- 海底などの状況役、本場・供託の点数加算
- 切り上げ満貫とダブル役満の採用ルール
